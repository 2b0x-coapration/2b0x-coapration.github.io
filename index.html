Why 2B0X

A calmer way to explore operating systems.

Import an image, press launch, and let 2B0X manage the VM while you focus on what you want to try.

◈

Launch from file

Upload an ISO, ZIP archive, or folder and let 2B0X package it into a bootable image.

◉

Keep your work

Every imported OS gets a persistent virtual disk so installs, files, and settings stay intact.

✦

Stay in control

Enjoy a dark interface, resizable view, history tracking, and useful error dialogs instead of crashes.

Before you begin

Built for Linux.

2B0X targets Ubuntu and Debian-based systems with QEMU/KVM available.

System requirements

  • Ubuntu or Debian-based Linux
  • Python GTK3 dependencies
  • QEMU system and utilities
  • genisoimage for packaging
  • /dev/kvm recommended for acceleration
